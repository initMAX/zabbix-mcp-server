Coming soon 🛈

A plugin loader is in development that installs additional MCP integrations from the upcoming initmax-mcp catalog. Focus is monitoring + the surrounding DevOps stack:

  • Nagios / PRTG - peer monitoring systems, query problems and host status from inside the same MCP session that already has Zabbix tools.
  • NetBox - source-of-truth IPAM / DCIM, resolve devices and IP addresses to Zabbix hosts, cross-reference rack / site / tenant context for problems.
  • Atlassian Jira / Confluence - create and link incident tickets, pull runbook docs, attach Zabbix problem context.
  • FastSpring - subscription / order data when monitoring SaaS-billing pipelines.
  • ... and any community-contributed plugin that follows the plugin contract (a standalone MCP server speaking MCP 2025-11-25 over stdio).

See issue #47 for the full design, and the upcoming docs/PLUGIN-DEVELOPMENT.md + examples/example-plugin/ reference implementation for plugin authors.
