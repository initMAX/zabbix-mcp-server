Compact Output 🛈
Response Max Chars 🛈

Tool prefix 🛈

Public URL 🛈
External URL clients use to reach this MCP server. Required when host is 0.0.0.0 and the server is exposed via a public DNS name or reverse proxy. No trailing path - the /mcp or /sse suffix is appended automatically. Must be https:// when TLS is enabled.

⚙️ Admin Portal

⚠️ All changes in this section require a server restart to take effect.
Admin Portal 🛈
For safety, disabling the admin portal can only be done in config.toml directly - if you could turn it off from inside the portal, you would lock yourself out and have to SSH in to recover. To disable: edit /etc/zabbix-mcp/config.toml on the server, set [admin].enabled = false, then sudo systemctl restart zabbix-mcp-server.
Admin Port 🛈
Separate port for admin UI. Shares host and TLS with MCP server.
Check for updates 🛈
When on, this server pings the GitHub releases API at boot, after every successful admin login (throttled to once per 60 sec), and on demand via the “Check now” button below. Shows an “Update vX.Y available” banner in the top bar when a newer release lands. Outbound HTTPS to api.github.com; no other data leaves the server. Off-line / restricted networks should disable this.

📜 Audit log

Mirrors the Zabbix admin Audit log panel. The master toggle is honoured at every audit write site; sub-toggles control what counts as an audit event and whether the server runs its own retention purge. Compliance frameworks (ISO 27001, SOC 2, NIS2) require an audit trail - turn off only with confirmation.
{% if not settings.audit_enabled %}
⚠️ Audit logging is currently DISABLED. Tool invocations and admin actions are not being recorded. Re-enable below to resume the audit trail.
{% endif %}
Enable audit logging 🛈
Required by ISO 27001, SOC 2, NIS2 and similar frameworks. Disabling is itself audited.
⚠️ Confirm audit disable
Audit logging is required by most compliance frameworks. Type DISABLE below to confirm.
Log background server events 🛈
Server-side events that happen without an operator action. Useful for forensics and to verify the housekeeping daemon is running.
Enable internal housekeeping 🛈
Daily rotation to audit.log.YYYY-MM-DD.gz + age-based purge. Disable if external log shipper handles this.
* Data storage period 🛈
Default 31d. Use Zabbix time-period syntax: s/m/h/d/w/M/y. Set 0 to keep all archives indefinitely.
Max file size (MB) 🛈
Rotation threshold per file in megabytes. 50 MB is the v1.30 default.

Enable forwarding 🛈
Local audit log keeps working regardless of forwarder state. Failed sends are queued + retried with exponential backoff.
Destination host 🛈
Required when forwarding is enabled. Resolved fresh on every reconnect.
Port 🛈
Defaults: 514 (UDP/TCP syslog), 6514 (TLS syslog).
Format / protocol 🛈
UDP is fire-and-forget (lossy under load). TCP delivers in order. TLS is TCP with mutual cert validation - prefer for cross-WAN destinations.
CA certificate (PEM) 🛈
Leave empty to use the system trust store (ssl.create_default_context()). Required when the SIEM uses a private CA.
Queue size 🛈
In-memory queue between the audit write path and the forwarder thread. Default 10,000.

✨ AI Template Generation

Server-side default for the “Generate with AI” button on the report template editor. Set a provider and key here so all admins share one configuration. If you leave the provider on “None”, each admin has to paste their own key in the AI modal every time.
Enabled
When off, the “Generate with AI” button is hidden from the template editor even if a key is configured.
Provider 🛈
Picking a provider preselects its default model and endpoint. Ollama allows empty API key for local unauthenticated setups.
API Base URL 🛈
Required for Azure OpenAI (deployment URL) and self-hosted Ollama. Locked for providers with a canonical endpoint.
API Key 🛈
{% if settings.ai_api_key_configured %} A key is already stored. Leave this field blank to keep it, or paste a new one to rotate. {% else %} Paste your Anthropic or OpenAI API key. Stored in [admin.ai].api_key with file permissions 0600. {% endif %}
Model 🛈
Leave empty for the provider's default. Provider defaults: Anthropic claude-sonnet-4-6, OpenAI gpt-5, Gemini gemini-2.0-flash, Ollama llama3.2, Mistral mistral-small-latest, Groq llama-3.3-70b-versatile.
Timeout (seconds) 🛈
How long to wait for the LLM to respond before giving up. Default 180 s. Large reasoning models (Claude Opus, GPT-5) regularly need 90-150 s for a full template; bump to 300 s if you keep hitting "read operation timed out".
Max tokens 🛈
Upper bound on the template length the LLM may produce. Default 8000 is enough for a full A4 report; raise only if generated output gets cut off.
